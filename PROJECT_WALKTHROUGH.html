🌟 Executive Overview

SanskritiVerse is an immersive multi-sensory educational portal engineered to transform passive monument reading into interactive spatial and acoustic discovery. Built under the Heritage Modernism aesthetic (Royal Navy #050814, Temple Gold #F59E0B, Sacred Saffron #EA580C), it combines 3D spatial reconstructions, GIS mapping, browser-native speech synthesis, accessible Indian Sign Language (ISL), and student gamification.

🛠️ Core Feature Inventory

1. 🗺️ Geospatial Heritage Map
File: js/components/map.js

Leaflet GIS map with custom dark parchment tiles, glowing saffron temple markers across India, zone filtering (North, South, East, West, Central, Northeast), and a slide-over detailed monument drawer.

2. 🏛️ 3D Time-Travel Monument Viewer
File: js/components/threeViewer.js

Three.js WebGL procedural 3D models for Taj Mahal, Konark Sun Temple, Hampi Stone Chariot, and Sanchi Stupa. Features a 1000 CE → 2026 CE Historical Time-Travel slider, 3 lighting environments, and GPU memory disposal.

3. 🎙️ Swar-Virasat: Voice Studio
File: js/components/voiceBot.js

Web Speech API synthesis narrating ancient regional legends in Indian accents across English, Hindi, Tamil, Telugu, Bengali, Marathi, and Gujarati. Includes a real-time HTML5 canvas audio wave visualizer.

4. 🤟 ISL Sign Language Avatar
File: js/components/signLanguage.js

Inclusive accessibility studio with a 2D vector avatar displaying certified Indian Sign Language (ISL) gestures (Namaste, Mandir, Surya, Ganga, Shilpi, Rajaraja Chola) in high-contrast navy-blue and skin-tone hands.

5. 🎮 Heritage Quest: Student Gamification
File: js/components/questGame.js

Archaeological trivia missions with timed multiple-choice questions, instant archaeological explainers, player XP accumulation, rank titles, and celebratory confetti particle bursts.

6. 🗓️ Seasonal Cultural Calendar
File: js/components/festivalCalendar.js

Pan-Indian harvest, vernal, sacred, and folk festival explorer with interactive modals detailing astronomical timing, mythological origins, sacred rituals, and traditional culinary items.

7. 🌿 Sustainable Heritage Travel Guide
File: js/components/travelGuide.js

Eco-friendly travel planner highlighting best visiting seasons, transit links, green electric shuttles/bicycles, and GI-tagged local artisanal handlooms to support traditional craft communities.

8. 🪷 Floating Heritage AI Chatbot
File: js/components/chatBot.js

Always-accessible floating AI guide equipped with deep knowledge on Indian dynasties, temple architecture styles (Nagara, Dravidian, Vesara), with a Listen to Answer text-to-speech button.

9. 🌐 7-Language Global Localization
File: js/data/translations.js

Instantaneous DOM localization supporting English, हिन्दी (Hindi), தமிழ் (Tamil), తెలుగు (Telugu), বাংলা (Bengali), मराठी (Marathi), and ગુજરાતી (Gujarati) via data-i18n attributes.

⚡ Memory & Performance Optimization

Optimization Technique Implementation Detail Impact
GPU Buffer Disposal Traverses and calls geometry.dispose() and material.dispose() prior to switching models Eliminates WebGL memory leaks when switching monuments
Low-Res Procedural Textures Canvas textures generated at 256×256 pixels rather than 512×512 Reduces VRAM consumption by ~75% per model
Hardware Memory Detection Queries navigator.deviceMemory and clamps device pixel ratio to 1.0 or 1.5 Prevents mobile browser crashing on lower-spec phones
Visibility API Throttling Listens to document.visibilitychange to halt the requestAnimationFrame loop Zero background GPU and CPU load when tab is inactive
